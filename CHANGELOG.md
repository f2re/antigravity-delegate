# История изменений

## 0.1.0 — 2026-07-30

- первая рабочая версия Codex skill;
- безопасный runner для headless-режима `agy -p`;
- одноразовые worktree для задач только на чтение;
- отдельные сохраняемые worktree и ветки для изменяющих задач;
- проверка чистоты исходного репозитория;
- структурированный JSON-результат и JSON Schema;
- удаление распространённых секретов из окружения дочернего процесса;
- профили архитектуры, безопасности, тестирования, исследования и реализации;
- установщик для пользовательского и репозиторного уровня;
- модульные и интеграционные тесты с имитацией `agy`;
- русская документация и пример политики разрешений.
