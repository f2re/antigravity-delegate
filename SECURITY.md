# Политика безопасности

Сообщайте об уязвимостях приватным способом владельцу репозитория. Не публикуйте рабочие эксплойты, токены, персональные данные и содержимое чужих репозиториев в открытых issue.

Основная модель безопасности описана в [`skill/antigravity-delegate/references/SECURITY.md`](skill/antigravity-delegate/references/SECURITY.md).

## Поддерживаемые гарантии

- отсутствие `shell=True`;
- обязательный `--sandbox`;
- отсутствие поддержки `--dangerously-skip-permissions`;
- изоляция через `git worktree`;
- очистка распространённых секретов из окружения;
- отсутствие автоматических commit, push, merge, deploy и миграций.

## Не являются гарантией

- корректность выводов модели;
- безопасность произвольных тестовых команд, разрешённых пользователем в Antigravity;
- защита от вредоносного кода внутри уже доверенного репозитория;
- работа sandbox на платформах, где она не поддерживается установленной версией Antigravity CLI.
