## Делегирование в Antigravity

Для независимого аудита архитектуры, безопасности, тестов, исследования документации и ограниченной реализации используй skill `$antigravity-delegate`.

Правила:

- задачи только на чтение запускай в режиме `read-only`;
- задачи с изменением кода запускай только в режиме `isolated-write`;
- не передавай агенту токены, пароли, ключи, персональные данные и содержимое `.env`;
- не делегируй публикацию, развёртывание, производственные миграции и необратимые действия;
- после выполнения самостоятельно проверь JSON-статус, `git diff`, изменённые файлы, тесты и сборку;
- не принимай вывод Antigravity без проверки по исходному коду или первичным источникам.
